# 牛来 A 版视觉与布局实现合同

## 目标

把首页改为“陪伴优先”，让用户先感到牛在陪自己看着任务，再看具体数据。保留一眼掌握全局的能力，不通过删除信息来减负。

基础视觉真值为：

`/Users/oreal/.codex/visualizations/2026/08/20/01a01f3c-b4b9-7590-acf0-17a0f3400faa/niul-three-directions.html`

本文件后续的“统一工作区补充合同”是用户在真实候选 App 上体验后的最终修订；与基础 demo 不一致时，以补充合同为准。

## 首页信息层级

1. 顶栏左侧是“牛来”，中间是“刚刚巡视”。右侧动作严格依次为：展开/收起、roll、牛记、大盘指数、设置、开关键。
2. 顶栏下方保留四态安静状态栏：拉犁、停犁、吃草、回棚。四态都用颜色区分，但只有“停犁”使用更高对比和强调底色。
3. 主内容不再出现“今日概览”和常驻大盘。使用“我看着呢。”作为陪伴式标题，下面是当前状态的自然语言说明。
4. 默认展示“停犁”任务。四态状态栏可点击切换，当前选择同步 `aria-pressed`。
5. Session 卡片保留两层信息，不使用更深的内层色块：
   - 第一行：左侧项目名；右侧工作摘要。
   - 第二行：左侧路径；右侧 `Agent · 相对时间`。
   - Agent 不使用胶囊标签。所有卡片的 `Agent · 相对时间` 共用固定右列并右对齐，不能随 Agent 名称或时间长度左右漂移。
   - 箭头独立为最右侧窄列，跨两行垂直居中。
   - 卡片左侧用状态色细竖线，整张卡片只允许极轻的语义底色。
   - 路径使用等宽系统字体，其他文字使用 macOS 系统字体。
6. Token 摘要保留在列表下方，视觉降级为安静的尾注信息。

## 面板和设置

- 牛记、大盘、设置都在同一个气泡工作区内切换，保留顶栏，覆盖顶栏下方的主页内容；主页 DOM 和状态不销毁、不跳转。
- 三个工作区使用相同的左、右边界、背景、圆角、内边距、标题高度和滚动边界，不再出现一个独立弹窗、一个凸起卡片、一个内嵌面板的混合形态。
- 牛记、大盘、设置、开关键菜单互斥，同时只打开一个；点击当前已激活的顶栏按钮或面板关闭键回到主页。
- 设置不再使用独立 `dialog`。它作为同层工作区，保留 A 版左侧导航：“外观与声音”“巡视范围”“大盘”。所有现有设置项必须被安置到对应分组，不删除功能。
- 开关键仍是控制中心，不是直接退出。顺序为：收起气泡、让牛开口、隐藏桌宠、切换深浅外观、彻底退出。

## 统一工作区补充合同

- 展开后的气泡基准宽度从 500px 收到 448px；360px 可用宽度下仍自适应且不得横向溢出。
- 顶栏基准高度 52px。六个顶栏按钮命中区 32-34px，图标视觉尺寸约 16px，统一线宽和激活底色。
- 主页陪伴区压缩到约 44px；“我看着呢。”为 16px，不再形成大标题压迫感。
- 四态状态栏文字与 Session 正文处于同一视觉量级。四态仍各有语义色，只有“停犁”有强调底色。
- Session 卡片基准高度 68-72px、圆角 13px、上下内边距约 10px；在保留可读性的前提下提高纵向信息密度。
- 统一字号层级：页面/面板标题 16px，项目名 14px，工作摘要和设置主标签 13px，正文/控件说明 12px，路径、Agent 与时间 11-12px。任何用户需要阅读的设置标签不得落到 8-10px。
- 设置工作区内左侧导航约 108px，右侧内容占剩余宽度；“牛来”“Session 气泡”等缩放标签使用 13px，并放在滑杆上方，避免被百分比和滑杆挤压。
- 大盘使用两列网格。现有 8 个指数显示为 4 行，不伪造第 5 行、不在本轮新增行情数据；指数名 12px，点位 15px/600，涨跌 12px/600。
- 牛记、大盘、设置的内容高度不同也不能改变外壳宽度、顶栏位置或面板边界；超出内容区时只在面板内部滚动。

## 深浅外观

- 全局统一覆盖首页、Session、牛记、大盘、设置、状态栏、Token 摘要、气泡和输入控件。
- 默认深色；用户选择写入 `localStorage`，下次启动恢复。
- 深色菜单显示太阳和“切换到浅色”；浅色菜单显示月亮和“切换到深色”。
- 不加载网络字体。圆润标题用：`ui-rounded, ".SF NS Rounded", -apple-system, BlinkMacSystemFont, "PingFang SC", system-ui, sans-serif`。
- 正文用 macOS 系统字体栈。禁止渐变、纯黑和纯白大面积背景。

## Session 文案映射

- 项目名优先 `cwdName`，其次 `title`、`label`。
- 工作摘要优先使用与项目名不同的 `title`；否则使用 `statusReason`；最后回退到四态文案。
- Runtime 使用 `label`，时间沿用现有 `timeAgo`。
- 路径沿用 `cwd` 或 `file`。
- 单条 Token 不再挤在 Session 主视觉中，但保留全局 Token 摘要和可访问描述。

## 交互与兼容边界

- 现有扫描、刷新、Session 打开、Roll、牛记保存、设置保存、隐藏桌宠、唤回和彻底退出行为不得退化。
- 折叠后只保留顶栏；折叠时关闭大盘、牛记和开关键菜单。
- 工作区须支持 Escape 回到主页，并保持现有键盘可达性、焦点可见性和按钮可访问名称。
- 360px 宽和常规桌面宽度均不得横向溢出；长项目名、摘要和路径必须正确截断。
- Session 截断优先级：项目名和 `Agent · 时间` 优先可见；摘要和路径使用省略号。窄宽度下不得换成三行，也不得让箭头或 Agent 元信息漂移。

## 验收边界

- 工程验证：新增结构契约测试先红后绿；全量 `npm test` 通过；`npm run pack` 通过。
- 产品实操：用最终打包 App 和隔离用户数据实际打开，覆盖首页、四态、真实 Session 长文本、牛记、大盘、设置、深浅切换、开关键、折叠/展开和重启后的主题恢复；核对三个工作区边界一致、设置不再弹出独立窗口、Session 两行对齐稳定，并截图交给用户判断视觉。
- 用户验收：主观舒适度、可爱程度与 demo 一致性最终由用户确认，工程和截图不能替代。

## 明确不做

- 不改扫描算法、状态判定、行情数据协议、牛记存储协议和 Electron IPC。
- 不新增外部依赖和网络字体。
- 不提交、不推送、不合并。
