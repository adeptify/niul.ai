# 牛来工作区舒展改版

## 完成等级

目标为 **4 — 内部完整**：真实 Session、行情和牛记数据继续工作，常态与展开态形成统一体验，关键状态、窄窗口、键盘操作和减少动效均可内部顺畅试用。此次不包含安装包与外部发布验证。

## 背景与问题证据

当前气泡把所有内容锁在约 448px 宽度内；大盘、牛记、额度和设置又以 420px 高的深色内层浮板覆盖主内容。Session 默认恢复为“等你”单状态筛选，用户先看到局部而不是全局。现有实现的直接 `hidden` 切换也缺少空间展开的连续反馈。

这带来三个体验问题：

1. Session 信息被压成两行，项目、工作摘要、路径、Runtime 与时间彼此争抢空间，难以快速获得全景。
2. 大盘 2×4、牛记纵向堆叠，在桌面窗口里仍按窄栏表达，操作显得拥挤。
3. 常态使用旧的深色叠层质感，而新版展开态采用更轻、更有层次的表达，两者不像同一套产品。

## 目标与用户场景

- 用户平时看到一张轻量、清楚的常态气泡，状态颜色与展开态一致。
- 用户点击 Session 汇总或“查看全部”后，气泡向左舒展，在一个视图中看到全部 Session；等待处理的任务排在前面，但不会隐藏其他状态。
- 用户点击大盘或牛记时进入同一工作区框架，获得更适合桌面宽度的 4×2 行情与左右分栏牛记。
- 用户点击任意 Session 后仍能切换到对应 Runtime；Memo 保存、提醒、行情刷新、额度与设置功能不回退。

## 范围

### 本次包含

- 统一常态 / Session 全景 / 大盘 / 牛记的壳层、纸张内容面、排版、间距、状态颜色与按钮反馈。
- 常态 448px；工作区约 680px，并在现有 720px Electron 窗口内从右向左展开。
- Session 默认展示全局统计；常态只提供优先预览，Session 全景展示所有记录并支持状态筛选。
- 工作区进入、退出和切换的柔和位移/淡入动效；尊重 `prefers-reduced-motion`。
- 键盘焦点、`aria-pressed` / `aria-expanded` / `aria-hidden`、鼠标穿透区域与窄窗口适配。
- 更新相关静态行为测试与真实 Electron 视觉验收。

### 本次不包含

- 修改 Session 扫描、状态判断、Runtime 聚焦、行情来源、Memo 存储或提醒协议。
- 新增行情指标、Memo 富文本、搜索、排序配置或批量操作。
- 重做设置和额度的信息架构；它们只需在新壳层内保持可用且不破版。
- 修改牛群模式、角色资产或声音系统，只允许为工作区展开暂停/恢复既有反应。

## 关键决策

1. **全景优先但不让常态膨胀。** 常态保留 448px，只展示最多两条高优先 Session；点击汇总或“查看全部”进入完整工作区。
2. **状态颜色是语义，不是装饰。** 工作中为绿色、等你为琥珀色、闲置为蓝色、不在线为灰色；颜色同时出现在汇总标签、Session 标签和细节强调中，并保留文字以避免只靠颜色识别。
3. **一个壳层，多个工作面。** Session、大盘、牛记、额度和设置共享工作区打开状态与宽度，不再用另一张厚重卡片覆盖主内容。
4. **等待优先但默认不筛掉其他状态。** 全景列表按 `waiting → working → idle → offline` 分组优先级排序；状态标签用于临时聚焦，再点一次回到全部。
5. **空间从右向左生长。** 现有 Electron 桌面窗口右对齐且宽 720px，扩大 `#pet` 与 `.bubble` 即可在窗口内部向左舒展，不改变扫描或窗口持久化协议。菜单栏模式继续限制为紧凑宽度。

## 数据、状态与模块边界

- `renderer/app.js`
  - 生产：当前工作面、全景开关、状态筛选和排序后的可见 Session。
  - 消费：现有 `snapshot.rows`、`snapshot.counts`、Memo 与行情快照。
  - 保持：`openSession`、Memo API、行情 API、额度 API 和设置保存调用不变。
- `renderer/index.html`
  - 提供工作区导航、Session 全景标题/筛选、常态预览入口，并保留既有元素 ID 供现有逻辑使用。
- `renderer/styles.css`
  - 提供统一材质、动态宽度、分栏布局、状态标签、交互与响应式规则。
- `electron/main.js`
  - 桌面窗口已有 720px 宽度，可承载工作区；菜单栏 popover 保持 448px 紧凑行为，不扩大窗口协议。
- `test/visual-layout.test.js`
  - 约束新工作区宽度、全景入口、默认全部状态、状态语义、宽/窄布局和减少动效。

- 工作区最大宽度先定为约 680px，给现有 720px 透明窗口保留左右安全边距；以真实截图为准允许在 660–688px 内微调。
